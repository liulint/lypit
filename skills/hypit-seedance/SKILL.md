# Hypit Seedance

本 Skill 是素材生成适配器，**不替代官方 `hypit` Skill**。参考视频分析、创意改编、Brief、Treatment、Script 和编排先按官方 Skill 完成；用户只要求看参考或讨论创意时，不应只读本扩展后直接给普通分析。官方 Skill 尚未找到时按工具 README 安装完整官方 Skill；不能以 `hypit` 可执行程序存在或本扩展已读取，代替官方 Skill 的安装及读取。只在确定需要 Seedance 素材生成时执行下面的报价和提交流程，生成后交回官方 Hypit 继续制作。

先确定 Go 工具源码的绝对路径。已安装 Skill 时读取其安装目录的 `installation-location.txt`；直接读取随包 `skills/hypit-seedance/SKILL.md` 时，将本 Skill 目录向上两级解析为绝对路径，并核实该目录存在 `go.mod`、`main.go`，即可直接使用，不要求全局安装或位置记录。两种方式均无法定位时，再定位用户提供的扩展文件夹，阅读其 README.md 的“AI 安装流程”。不猜路径、不修改官方 Hypit 或官方 Skill。工具源码位置与用户视频项目位置是两个目录。

## 从剧本到报价

在 Hypit 或配置本扩展的项目中，用户明确要求生成视频，或在确定剧本后说“生成视频吧”“按这个方案做”“开始制作”等时，由官方 Hypit 主流程进入本适配器；除非用户明确指定其他服务，无需再问是否使用 Seedance。先检查本地工具，不因没有内置视频生成工具就跳去搜索插件或声称无法生成。只看参考、评估创意、改剧本时回到官方 Skill，不运行生成报价或提交。

沿用官方 Hypit 已确定的剧本，整理成最终提示词；不要把整段对话当提示词，也不要擅自拆分剧本生成多条。对话已经明确的时长、比例等优先于默认值。将提示词通过文件工具写入用户项目的 UTF-8 文件，所有素材均使用绝对路径。选择项目内独立任务目录，将绝对路径传给 `-out`；不要把历史任务和生成视频放回工具分发目录。

本地参考视频可以只用于观察创意和风格，不自动作为 API 输入。不能传本地路径给 `-video-url`，也不能擅自上传；需要直接参考时使用用户提供的公网 URL，或把选定截图作为图片参考。最终确认区分“仅创意参考”的原视频与实际传给 API 的素材，无实际输入时明确展示“参考素材：无”。

使用 `go -C "$TOOL_ROOT" run . -quote -json -prompt-file "$PROMPT_FILE" -out "$JOB_DIR"`，并附上本次所有明确参数及参考素材。重复图片使用 `-image`，视频只用 `-video-url` 公网地址。声音关闭必须用 `-audio=false`。接入点和未知模型必须先核实对应模型，再显式传 `-price-model`，不能猜价格。

默认 Mini、480p、**有声**、5 秒、16:9、1 条。支持三种模型、480p/720p、4–15 秒整数及官方固定比例。素材限制和完整接口见工具 README.md。`-quote` 无付费；有视频参考时会匿名读取素材校验。`can_submit=false` 时先解决素材或模型映射问题，不提交。

## 最终确认是提交前必经步骤

每次实际生成前，**集中展示并询问用户确认**以下所有项目；即使全用默认值也不能省略：

| 参数 | 展示内容 |
|---|---|
| 模型 | 最终名称和实际调用 ID；接入点同时展示计价模型 |
| 分辨率 | 最终分辨率 |
| 输出声音 | 有声／无声 |
| 时长 | 最终秒数 |
| 比例 | 最终固定比例 |
| 提示词 | 本次完整最终提示词 |
| 参考素材 | 所有选用的图片、视频及视频时长；没有明确写“无” |
| 数量 | 本次生成总条数 |
| 价格 | 元/百万 token 单价、单条预估、整批预估、计价来源及核实日期 |

注明最终按实际计费 token `usage.completion_tokens` 核算，刊例价估算不等于账户账单、不自动套用折扣。

若 JSON 的费用上界为 null，必须展示“上界未知”，不得只展示公式下界，更不能称为封顶价。若没有可核实的费用范围，直接写“费用未知”。用户要求明确预算上限时，先核实官方最低 token 规则或让用户选可估算的规格，不能先提交。官方示例范围须标明是相同输出规格的宽范围，不是针对本次参考时长的精确费用。

展示后等待用户明确确认。修改任一参数、提示词、素材或数量时，重新报价、重新集中展示最终参数和报价，再取得确认。不把模糊的继续讨论当作授权，不由 AI 代替用户确认。

## 提交及异常处理

用户已确认且参数未变时，使用同一组参数，附上报价返回的完整 `-confirm <confirmation_id>`，只提交一次；不要再次询问。确认标识绑定素材内容哈希，发生变化时旧标识会被拒绝，重新报价确认。

工具报错、超时或中断后先检查 `run.json`，绝不自动重新执行生成命令，也不换目录规避重复任务保护。POST 结果未知但未保存 ID 时，告知用户到官方控制台核对；不能假定失败。批次部分失败时仅恢复已保存 ID，不补提交剩余项；新生成剩余项须另行报价确认。

`go -C "$TOOL_ROOT" run . -json -resume "$JOB_DIR/run.json"` 只恢复同一批已知任务，不创建新任务，因此不重新确认生成。恢复只搭配 `-json`、`-poll`、`-wait`，不传模型等新参数。锁目录残留时确认旧进程已退出再处理，不并发操作同一任务目录。

## 结果交付

展示每条任务 ID、状态、实际模型、实际规格、`completion_tokens`、`total_tokens`、人民币刊例价估算和计价依据。缺失字段写“未返回”；费用未知时说明原因。下载失败也给出记录绝对路径，说明用量已保留，并恢复同一任务；不重复累计费用、不覆盖已有文件。

生成视频是素材，不代表已经完成官方 Hypit 的编排和导出。按用户原任务需要继续使用官方 Hypit 引用这些素材，报告最终视频或素材的实际保存位置。

密钥只读 `ARK_API_KEY` 环境变量；不在聊天索取、打印、记录或写入命令历史。不改变官方 API 地址来排查网络，不把带凭据的 Ark 客户端用于媒体下载。
