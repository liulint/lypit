# 映序 · Lypit Studio

重新构建的本机 AI 短片工作台：**Go + Gin / React + TypeScript + Vite + Ant Design 6.7 / SQLite**。无需登录，打开本机地址直接创作；前端构建后由 Gin 同源提供。运行目标为 macOS、Linux。

## 启动

普通用户使用发行包，无需 Go、Node.js 或 C 编译器。源码开发需要 Go 1.25+、Node.js 22.12+，SQLite 使用纯 Go 驱动，不需要 CGO。

发行包：macOS Apple Silicon、macOS Intel、Windows x64 分别打包。解压到可写目录，macOS 运行 `start.command`，Windows 运行 `start.cmd`；服务启动成功后自动打开默认浏览器，保持终端打开，也可手动访问 `http://127.0.0.1:8080/`。每包只有对应平台后台、前端 `web/dist`、启动脚本和发行说明；用户数据独立保存在 macOS 的 `~/Library/Application Support/Lypit Studio/` 或 Windows 的 `%LOCALAPPDATA%\Lypit Studio\`。更新时关闭程序，解压新包并启动即可复用数据；删除旧程序文件夹不会删除个人数据。服务配置页可打开数据目录、备份完整数据；备份包含素材、任务、配置和加密密钥，须妥善保管。源码开发仍使用项目 `data/`，显式 `-data` 可指定目录。外部 npm 版 CLI 仍需要其自身的 Node.js 环境。发行程序尚未代码签名/Apple公证，首次运行可能需要在系统安全提示中允许。

开发者生成发行包：`npm --prefix web run package`；输出到 `.cache/releases/<时间戳>/`，不包含本机数据或凭据。Windows 源码启动使用 `scripts\start.cmd`（CMD/双击）或 `scripts/start.ps1`（PowerShell）；macOS 使用以下命令：

```sh
sh scripts/start.sh
```

打开 **http://127.0.0.1:8080**。首次启动会安装前端依赖、构建前端和后端。Ctrl-C 停止；脚本使用 exec，不保留开发服务器。

可指定端口和数据目录：

```sh
sh scripts/start.sh -listen 127.0.0.1:8081 -data /your/private/data
```

无需 MySQL、Redis、ComfyUI，也没有用户、登录或权限模块。无登录模式只允许回环地址监听；保留本机 Host 与跨站写入校验。

## 使用流程

1. **新建作品**：填写标题、故事想法和视觉风格，选择9:16竖屏或16:9横屏、10～180整数秒目标时长，默认竖屏60秒。
2. **故事分析**：查看并确认一次文本分析报价，生成剧本与角色、场景、道具清单，可继续修改。
3. **参考素材**：每个角色先生成一张正面主图，逐张人工确认；之后每个角色生成一张2×2设定图（正面、侧面、背面、近景），本地裁切四视角。同时按清单生成场景、道具。确认所有素材后锁定。
4. **分镜审片**：先单独确认文字规划报价，按总体剧本的场景、时间段和台词拆镜，不强制均分。通过全片时间轴与总览表通读，居中大弹框（宽高约占可视区域90%）对照原文编辑静态首帧、视频动作和台词；逐镜标记待审核、需修改或已审核，状态随草稿保存。修改已审核内容会取消该镜审核，修改时长也会取消后续镜头审核。任意一镜审核通过后，可点击“试做本镜图片 · 查看报价”，自动保存草稿并单独确认这一张图片的报价；出图后在“查看本镜试做”中确认画面，再单独报价生成本镜视频，无需等待其他镜头审核。全部审核通过且时间正确后，点击固定底栏的“确认采用规划”，内容未变的试做图片和视频会沿用，其余缺图再单独确认生图报价。重新规划期间原素材保持不变，采用后原图、原视频保留在历史素材区及ZIP导出。
5. **视频与导出**：单独确认已审核镜头的视频数量和准确秒数（新规划单镜1～12秒，合计为所选时长）；角色对白随视频生成，旁白模式另生成统一旁白。完成后确认本地合成，使用 FFmpeg 合成导出，通过尺寸、时长、音轨和完整解码检查后发布成片。
6. 下载 MP4、独立 SRT，或包含项目、采用素材、候选图与任务记录的 ZIP。

分镜阶段先生成独立文字草稿，等待人工审核；文字规划任务本身不提交生图。已保存且审核通过的单镜可分别确认图片、视频报价先行试做，结果保存在规划草稿中，不替换原有正式分镜。新规划校验时间段连续性、分镜与原文段落对应、总时长、角色引用及对白原文与顺序，剧情动作语义仍须人工审核。生图仅使用独立静态首帧描述，视频使用后续动作与运镜，不用动态段落直接生图。审核后单独报价，每镜一张图，最多两张图片并行制作。镜头规划与图片逐张保存到项目，已出图镜头即可编辑台词、人工确认并单独报价生成视频，无需等待整批出图；未出图镜头保持禁用，图片重生成与整批锁定仍需等待整批结束。后台出图只合并图片，不覆盖期间的台词、确认与视频。旧任务保留原报价的两张授权，按固定作业ID归位，不以返回顺序决定。失败时停止启动后续生图，已提交的并行请求继续收回并持久化结果，避免把可回收的结果变成未知；用户取消时停止本地进程树。恢复任务先检查并收回已有回执，存在未知提交时不启动新付费请求。普通预览接口只返回分镜字段，不返回配置或凭据。

本地服务升级可以留下明确“尚未提交”的暂停占位，让旧任务在下一次模型调用前停下，当前已提交请求继续收回。新版恢复时只清除精确匹配该本地协议的未提交占位，不能清除真实 submitting/rejected 回执；任务ID、原报价、配置快照与素材版本保持不变。

## 模拟与真实模型

**默认是本地模拟模式**：模板剧本、程序绘制的示意图、静止画面视频和静音旁白。没有真实模型请求，不产生模型费用；界面、任务与导出项目都标记为模拟。用于验证整个制作流程，不代表真实 AI 成片效果。

本机视频模拟、合成与导出只需要 `ffmpeg`、`ffprobe`。故事编辑和图片模拟不需要这些工具。服务配置页显示工具是否可发现，并支持重新检测。缺少 FFmpeg 或 ffprobe 时，可点击“安装缺少的工具”，macOS 通过本机 Homebrew 执行固定命令 `brew install ffmpeg`，Windows 通过 WinGet 的 `Gyan.FFmpeg` 固定包以用户范围安装（两者都包含 FFmpeg 和 ffprobe），显示安装状态并在完成后自动重新检测和验证可执行性。已有工具不重复安装；重复点击合并到同一次安装，关闭页面不影响安装，服务关闭会停止安装进程组。安装最多等待20分钟，失败后可重试或在终端安装。未找到 Homebrew 或 WinGet 时提供对应官方安装入口；不会静默安装包管理器、请求管理员密码或在启动/保存配置时自动下载软件。桌面启动时检测各平台常用安装目录，Windows同时检测WinGet的链接和FFmpeg包目录，安装完成后无需重启服务。安装说明参考 [Homebrew FFmpeg 配方](https://formulae.brew.sh/formula/ffmpeg)。

通过侧栏两个独立页面配置：“厂商管理”新增本地CLI或远程API连接，“服务配置”为文本导演、图片、视频、旁白选择厂商和模型。一个厂商可供多个兼容能力复用。页面修改先进入草稿，点击“保存配置”后才生效。默认仍使用本地模拟；切换到“真实服务 · CLI / API”后也须逐阶段确认报价。

远程API厂商提供以下协议适配器，须自行填写准确模型 ID：

| 能力 | 协议 | 要求 |
| --- | --- | --- |
| 文本导演 | OpenAI 兼容 `/chat/completions` | JSON 对象输出 |
| 图片 | OpenAI 兼容 `/images/generations`、`/images/edits` | 多参考图 multipart `image[]`；单张 base64 或公网 HTTPS 图片 |
| 视频 | 方舟 `/contents/generations/tasks` | 支持 `reference_image`、480p、所选画幅、5～8秒的模型 |
| 旁白 | OpenAI 兼容 `/audio/speech` | alloy 音色、WAV 输出 |

接口代码基于 [OpenAI Images 文档](https://developers.openai.com/api/reference/resources/images/methods/edit) 和 [火山视频生成文档](https://docs.volcengine.com/docs/lake-ai-service/video-generation-enhanced-edition-basic-edition?lang=en) 的请求形式。兼容服务及具体模型必须实际验证；配置成功不等于支持所有参数。**尚未使用真实凭据完成远程出片验收**。

远程厂商默认可直接在页面输入 API Key，点击“保存到配置草稿”后，再点击页面“保存配置”生效。再次编辑时不回显密钥；留空保留原值，输入新值即可替换。也保留“环境变量（高级）”方式，例如 `TEXT_API_KEY`、`IMAGE_API_KEY`、`ARK_API_KEY`、`VOICE_API_KEY`。

本机密钥采用 AES-256-GCM 加密，密文按不可变版本保存在私有运行目录 `data/credentials/`，主密钥为同目录 `master.key`；macOS目录权限0700、文件权限0600；Windows使用仅当前账户与SYSTEM可访问的受保护DACL。SQLite、任务配置只保存版本引用，不保存原文；普通接口、项目ZIP、报价、浏览器持久化及日志不包含密钥原文。输入只在页面内存中暂存，保存成功或离开页面后清除。更新密钥使未确认报价失效；已确认任务仍引用原密钥版本，恢复不依赖新密钥。保存失败保留旧配置，不批量清理旧密文。备份或迁移时应同时保留密文与原主密钥；主密钥丢失无法解密，不会静默生成替代密钥。本机加密用于避免明文落盘和误泄露，不抵御已能读取整个数据目录的同一系统账户。无需登录不等于远程模型免费；远程报价明确显示金额未知，需接受按实际用量收费，没有可靠金额上限。

修改模型配置使未确认报价失效；已确认任务保留原配置快照。一个项目不混用模拟与远程生成素材；切换模式后请新建作品，或切回原模式继续。

## 数据与恢复

- `data/studio.db`：项目、历史版本、报价、任务、配置快照和请求回执；SQLite WAL、单连接事务、进程排他锁。
- `data/media/`：本机媒体文件，不将图片或视频大文件塞入数据库。
- `data/productions/`：逐次合成的镜头中间视频及拼接清单；既有历史运行产物保留。
- SQLite 历史保留每次项目修改；页面可只读查看最近50版。归档可恢复，不删除项目。

报价绑定项目版本、供应商配置版本、阶段与实际缺少数量，有效15分钟。重复确认同一报价返回同一任务。角色主图、设定图及分镜图按文件哈希校验；不绕过人工确认。

付费提交前写入持久化意图，响应保存后才解析；提交中断且无响应时，恢复也不会重发 POST。已知视频任务 ID 只查询下载。重启将未完成任务标记为中断，用户显式恢复。取消停止本地等待与新提交，供应商已接收的工作可能继续并计费。放弃后可重新编辑，但新任务仍需报价，须自行核对原远端工作，避免重复消费。

后台任务运行期间阻止修改项目；失败、中断、取消后先恢复或明确放弃，避免旧执行结果覆盖新内容。任务总执行时间限制45分钟。更换环境变量中的实际凭据后，历史任务恢复会使用当前进程环境中的凭据，应保持原供应商账户可访问。

停止服务后备份整个 `data/`，包含数据库 WAL、所有媒体和历史运行产物；不要在运行中替换数据库。本轮重建不包含旧数据导入或旧版本迁移。

## 成片边界

用户可选择9:16竖屏（360×640）或16:9横屏（640×360），目标时长为10～180整数秒，默认竖屏60秒。剧本、分镜数量、图片构图、视频参数、报价数量与最终合成均使用项目规格；四格设定图仍固定正方形。已有缺少规格字段的项目与历史任务按原竖屏60秒读取，不扩大历史授权。修改画幅或时长会重置分析、资产与后续制作，旧报价失效，历史版本与文件保留。字幕为按镜头窗口分句的独立 SRT，未烧录、未做逐字语音对齐；统一旁白按目标时长截断或补静音，需要人工听看。视觉质量、四格布局与镜头连续性由人工审片确认，尚未实现自动视觉模型审核。当前不提供本地素材上传、CLI视频/语音生成、复杂转场和逐镜时间轴编辑。

最终合成直接由 FFmpeg 完成：统一镜头尺寸、24fps及像素格式，按已确认顺序拼接，加入旁白并按目标时长截断或补静音，以 H.264/AAC MP4 导出并启用 faststart。字幕单独保存为 SRT。先写入临时成片，经 ffprobe 检查尺寸、时长和音轨，再由 FFmpeg 完整解码检查，通过后原子改名发布；失败保留中间文件，不提交模型生成请求。

## 本地CLI厂商

支持 Codex CLI 的文本规划与图片制作，以及 Claude Code 的文本规划，复用本机已有登录，不自动安装或登录。厂商可填写绝对可执行文件路径，留空从后端PATH查找；不支持拼接命令或自定义参数。页面状态仅检测文件可执行性，不运行模型、不代表账户已登录。

Codex 使用 `exec --sandbox read-only --ephemeral`、标准输入提示词和独立目录最终响应文件；Claude Code 使用 `--safe-mode --print --output-format json --tools "" --no-session-persistence`，不启用内建工具。Windows 自动识别原生 `.exe` 和官方 npm `.cmd`；后者直接使用 Node 执行官方 JS 入口，不经 cmd.exe 拼接参数。Windows安装位置会同时检查用户npm目录和本机常用位置；取消时停止整棵子进程树。实现参考 [OpenAI Codex exec](https://learn.chatgpt.com/docs/developer-commands#codex-exec)、[Claude Code CLI](https://code.claude.com/docs/en/cli-reference)，未修改官方CLI、Skill或登录配置。CLI可能访问其云端厂商并消耗账户额度，不能当成离线免费推理。

Codex CLI 可同时绑定文本导演和图片制作；Claude Code 仅可绑定文本导演。图片也可绑定OpenAI兼容API，旁白使用OpenAI兼容API，视频使用方舟API。Codex 生图使用独立任务目录、`exec --sandbox workspace-write --ephemeral`、`--image` 参考图及结构化产物回执，通过本机 imagegen 技能调用内置生图工具。图片能力中的模型 ID 是 Codex 执行模型，留空使用CLI默认值，不是图像模型 ID。需要已安装的 imagegen 技能与当前CLI账户可用的内置生图工具；缺少能力时失败并保留提交记录，不自动安装、不改动官方Skill、不切换API脚本。每个报价图片任务要求一次生图调用，不自动迭代。

后端仅从回执指定的 `$CODEX_HOME/generated_images/` 原始产物收回本次图片，不扫描或挑选其他历史文件；检查路径、时间、类型、体积、完整解码、横竖方向与四格正方形约束，再复制到项目素材并持久化原响应。CLI提交前写入执行意图，保存响应后解析；结果未知、进程中断或响应缺失时，不自动重跑。已有完整产物回执可只做本地收回；收回后不依赖原CLI或原产物继续存在。取消会停止本地进程组，远端已经开始的推理可能仍计费。

原来的四组API配置会在读取时按原地址、凭据变量与协议整理为厂商；不改变历史任务的快照，不调用模型。已绑定厂商不能移除，需先调整服务绑定；移除未使用厂商后，历史任务仍保留完整旧配置。厂商配置与服务绑定都受版本校验，修改后未确认报价失效。真实CLI与真实远程生成均需配置账户后另行验收，默认测试使用假的本地CLI，不消耗模型额度。

### 声音方式

新建作品及“故事与剧本”阶段可选择“角色对白（动物自己说话）”或“旁白讲述”，新作品默认为角色对白。旧项目和已确认任务保留原旁白模式。仅切换声音方式保留角色、场景与分镜图片，清空镜头台词、视频及成片并取消分镜确认；核对原剧本并重新填写、确认台词后继续报价。

角色对白按“角色名：台词”逐行编辑，可留空表示只有环境声。有声视频由支持同步音频的模型生成，不调用统一旁白服务；FFmpeg 保留各镜原声音轨，缺少音轨时停止，恢复只查询、下载原供应商任务。台词准确度、跨镜音色和口型需要人工试听检查，程序不能自动保证。模拟模式始终为示意图和静音。字幕为按镜头窗口排布的独立 SRT。

### 规划单镜试做

规划总览中，每镜审核通过后点击“试做本镜图片 · 查看报价”。保存和报价都不会调用模型；确认图片报价后仅生成这一张。出图后点击“查看本镜试做”，人工确认画面与既定台词，再查看并确认本镜视频报价。其他镜头可保留待审核状态，最终合成仍需完成整份规划和全部镜头。修改试做镜头的文字、时长或引用会解除旧图片及视频关联，历史文件保留；未改动的结果在保存草稿、采用整份规划后继续沿用。

### 分镜图片与修改建议

新报价每镜只生成一张图。图片旁点击“重新生成”，先填写修改建议，再确认当前镜头的一张图的报价；未确认前不提交生成。新图完成前保留原图，失败或结果未知时先恢复原任务，不自动重提。新图完成后重新确认画面，其他镜头与台词保持原样。旧任务仍按当时已确认的数量恢复；旧项目显示当前选中的一张，其他旧图保留在本地文件与历史记录中。

### 单镜视频

分镜卡片确认画面与台词后即可点击“生成本镜视频”，无需先确认其他镜头或锁定全部分镜。报价只含该镜头的一段视频与准确秒数，不单独生成统一旁白。卡片可直接预览视频；“重新生成本镜视频”先填写修改建议，再确认单镜报价。新视频成功前保留原视频，失败或结果未知时恢复原任务，不自动重提。新视频使用独立文件，旧视频和历史版本保留。全部分镜锁定后，批量制作只补齐缺少的视频及必要的旁白，成片需重新合成检查。

### 厂商连接与服务配置

侧栏“厂商管理”统一维护 Codex CLI、Claude Code、火山方舟（豆包）、阿里百炼（千问）及自定义兼容 API 连接。同一连接可用于多个制作服务；厂商支持多个账号或区域配置。先保存厂商，再获取模型目录；获取目录只查询元数据，不执行推理。

“服务配置”分别为文本导演、图片制作、视频生成、统一旁白选择厂商与模型，并管理本地模拟/真实服务和 FFmpeg 工具。目录模型按当前已适配的接口筛选，未适配模型在厂商目录中显示“待支持”；CLI 可沿用默认模型或填写执行模型 ID。自定义模型 ID 保留为高级入口，未识别的 ID 标记未验证，实际制作仍需确认报价。

方舟使用连接根地址的 `/models`；百炼模型目录使用区域及工作空间 ID 对应的 `/api/v1/models`，与兼容推理根地址分开处理。目录按连接和凭据版本缓存十分钟，支持手动刷新；刷新失败保留原列表及服务选择。百炼本轮开放兼容文本调用，方舟开放兼容文本及现有视频调用，其他原生多模态适配尚未开放。

两页独立保存并检查配置版本，修改中的草稿不会被后台轮询覆盖。厂商或服务变更会使未确认报价失效；模型目录刷新不改变制作配置版本，历史任务继续使用原有连接与凭据快照。

### 视频输入与连续镜头

新报价默认“独立镜头·严格首帧”：把本镜已确认分镜图以 `first_frame` 发送，固定角色、场景和道具参考先用于分镜生图，不与严格首帧混传。卡片可选择：

- 首尾帧控制：本镜图为首帧，选择本项目另一张（或同一张）已确认分镜图为尾帧；不额外生成尾帧图。
- 多参考：本镜图作开场引导，并传本镜引用的固定角色、场景、道具主图（去重，最多9张）；全部使用 reference_image，不承诺严格首帧。
- 延续上一镜：须先完成上一镜视频，绑定其本地文件哈希和原供应商任务。只查询原任务取得可用的视频链接，不自动上传任何本地视频；同时使用本镜固定素材参考。需要支持视频延长的模型，输出只要求新片段；若输出时长不符则停止，不自动重提。

报价展示生成方式、实际图片及来源；确认后输入与模型快照固定。自定义模型ID能力需要用户核实，已知不支持全模态的Seedance 1.x会阻止多参考和延续。2.5严格帧/延长使用adaptive比例。上一镜替换后，旧续接视频仍保留，但需重新制作后再合成。整片批量补齐采用严格首帧，其他模式须逐镜选择并确认。旧任务没有输入清单时仍按原单参考图语义恢复，不改写已确认任务。模拟模式只验证输入与依赖，不能用于判断人物、运动或口型效果。

约束依据：火山方舟官方创建任务、Seedance 2.0/2.5文档。严格首帧/首尾帧与多模态参考互斥；视频延长不保证逐帧连续、跨片段速度或音色一致，需要人工预览。

CLI 执行诊断保存在 `data/cli/<任务ID>/<作业ID>/cli-execution.json`，包含退出码、耗时和有大小上限的标准输出/错误输出尾部。落盘前屏蔽已配置凭据、敏感环境变量值、认证字段和 URL 查询参数；不单独记录启动参数、环境或提示词。文件仅保存在本机，不经普通任务接口或导出提供。每次实际执行只写一份，恢复只收集已有回执，不重跑 CLI，也不覆盖原日志。旧任务已丢弃的输出无法补录。

分镜缺图时使用“补生成 · 查看报价”，每次只生成选定镜头一张，已有图片保留。停止的原任务仍保留到新报价确认；确认页单独说明新调用及原请求费用未知，确认后原任务转为“已转单镜新任务”，不能再恢复覆盖新图。“恢复已有结果”先核对原回执，回执为空或缺失时立即说明原因；它不能代替重新报价生成。

新图片报价支持超过5份参考素材：按角色、场景、道具自动制作最多5张参考板；不同类别不混放，原图不变，不裁切、不缩放、不旋转、不丢素材。每板边长不超过4096、像素不超过8388608、编码不超过32MB。报价页展示素材数量、参考板尺寸和每份素材的像素位置，并绑定原图与参考板哈希；方案变化须重新报价。装不下会停止并提示在补图弹窗“本次参考素材”中主动选择，默认保持全部引用；选择只影响本次新报价，不提前修改项目或旧任务。合板是本地处理，不调用模型，最终仍仅生成1张分镜，不拆分付费、不自动重试。整批初次生图使用已人工采用的规划，所有缺图的参考板预检通过后才提交生图；单镜试做仅使用当前已保存、已审核镜头的参考板，仍需单独确认报价；合不下保留规划并停止。旧确认任务和原回执按原语义恢复，不因合板升级重新提交。

图片细改使用“基于当前图修改”，整张重画使用“重新生成一版”。编辑弹窗显示固定的当前底图，可分别填写修改内容与必须保留的内容；底图版本改变时要求重新打开，禁止静默换底图。当前图独立占1个输入，辅助角色/场景/道具最多4张参考板，也可全部取消辅助素材；报价绑定底图、内容、来源哈希与版面，只授权1张修改图，确认后才执行。原图与各版本文件保留，“新旧对比与切回”可对比编辑来源并选择已有版本，不调用模型、不计费。新编辑成功或切换版本会取消本镜确认、解除当前视频关联，旧视频文件保留；确认新画面后再生成视频。CLI和API均以第1张图片为唯一编辑目标，其他输入仅辅助校对；未知执行只恢复已保存结果，不自动重试或切换模型。

### 视频重做方式

分镜表格的“重新生成本镜视频”会先要求选择“基于原视频修改”或“重新生成一版”，填写修改建议，再确认仅当前镜头的报价。修改原视频会绑定当前视频文件、哈希和原供应商任务，通过原任务查询链接并核对内容，不上传任意本地视频；不支持的模型、过短视频或失效回执会在提交前停止，不自动改成重新生成。重新生成一版默认使用已确认分镜图作严格首帧，不传本镜旧视频。

已核对的 Seedance 2.0/2.5 视频编辑遵守原片规格；2.5 使用原生 edit 任务、adaptive 画幅与自动保持原片时长参数，完成后检查实际时长。含视频输入的报价保留输入视频及最低用量带来的费用不确定性，生成后的参考费用按含视频输入档折算。失败或未知结果保留原视频，恢复只查询/下载原任务，不重发；成功的新视频使用独立文件，其他镜头不重做。

系列剧入口支持通用共用设定与素材版本、分集管理、逐集制作及人工确认前情，原单集制作保留。操作和版本边界见 [Drama工作流](docs-drama-workflow.md#系列剧)。

发行版更新与备份：启动脚本通过 `-user-data` 使用固定系统用户目录，`-data` 显式参数优先。更新前等待制作任务结束并正常退出，备份后再替换程序；未知提交只恢复原任务，不重新调用模型。备份保存在数据目录同级的 `Lypit Studio Backups/`，包含 SQLite 一致性快照、全部普通文件和 SHA-256 清单；`.incomplete-` 开头的目录表示失败副本，不可作为完整备份。恢复时停服，将完整备份复制到独立空目录，以 `-data` 指向该目录验证后再使用，保留原目录；不要混合不同备份。数据库高于程序支持版本时拒绝启动，禁止用旧版强行打开。今后修改数据库或持久化内容格式时必须提升数据版本、补充事务迁移及兼容性测试，先完整备份再迁移，失败停止；不支持的数据版本不得自动重建。
