# 映序 · Lypit Studio

本机运行的 AI 短片工作台。输入故事想法，模型自动制作角色与分镜；审核图片、旁白和提示词后，集中确认视频费用，再自动制作约一分钟的中文竖屏短片。

## 快速开始

需要 Go 1.25+（SQLite 使用 CGO，需本机 C 编译器）、Node.js 22+、FFmpeg、ffprobe，以及已安装的官方 Hypit CLI。默认使用本地模拟服务，不需要 API Key，不产生模型费用。模拟图片为程序绘制，模拟旁白为静音；仅用于验证工作流。

先构建前端：

```sh
cd web
npm install --registry=https://registry.npmmirror.com
npm run build
```

再从仓库根目录启动后端：

```sh
cd server
go run .
```

按 `config.yaml` 中的后端端口打开页面。开发前端可在另一个终端进入 `web` 后运行 `npm run dev`，使用配置中的前端端口访问（初始为 http://127.0.0.1:5173）。两者都只供本机使用。使用完后在启动终端按 Ctrl-C 停止。

后端地址和前端开发端口在仓库根目录的 `config.yaml` 配置，例如：

```yaml
server:
  host: 127.0.0.1
  port: 8080
frontend:
  port: 5173
```

`server.port` 控制后端端口；`frontend.port` 控制 `npm run dev` 的页面端口，前端固定监听本机127.0.0.1。修改任一端口后需重启后端和前端开发服务，后端的开发来源校验及前端代理会同步读取配置。前端端口占用时直接报错，不会自动换端口。旧配置未填写 `frontend.port` 时使用5173。构建后的前端由后端同源提供，仅使用后端端口。

后端默认读取 `<root>/config.yaml`，可用 `-config /绝对路径/config.yaml` 指定其他配置；`-listen 127.0.0.1:8081` 优先覆盖文件中的后端监听地址（使用这些命令行覆盖时，开发代理仍读取根目录配置）。配置缺失或格式错误时启动会报错，不会静默回退。

生产构建运行方式：在 `server` 执行 `go build -o ../.cache/lypit .`，然后从仓库根目录执行 `.cache/lypit -root .`。数据默认存入根目录 `data/`，可通过 `-data` 指定绝对目录。

## 创作流程

1. 输入故事创建项目，可上传最多3张 PNG/JPEG 已有参考图，以及可选背景音乐。上传图与后续生成的角色图库是两回事。
2. 点击“分析故事，准备参考素材”，查看并确认一次文本调用报价。系统只提取故事概要、1～3个角色、1～3个场景、最多2个关键道具，不生成图片或分镜。
3. 在素材设定中编辑外观、服装、固定特征、场景和道具描述，并手动关联已上传图片。保存前先预览影响范围。按清单实际角色数量确认主图报价，每个角色先生成一张正面全身图。
4. 逐张人工确认主图。模型审核通过不能代替人工确认；模型未通过或历史素材需要填写接受理由，未完成的审核不能接受。主图确认后，再按实际缺少数量报价生成侧面、背面、面部近景，以及场景、道具图片。全部为独立图片，其他角色角度引用已确认主图。
5. 人工确认全部参考素材并锁定，才能生成整套分镜。分镜导演使用锁定的资产清单，分镜图片引用相应视角、场景与道具；不重新生成或静默替换参考资产。导演需要新增资产时暂停，返回素材设定处理。
6. 分镜仍为8～12镜，每镜两张候选，比较后优选；两张均未通过时最多补一张条件修复图。审核画面、提示词、旁白和实际引用后，再锁定分镜、确认视频费用并制作成片。
7. 生成统一旁白和按实测旁白时长分句的字幕，完成转场及本地合成，下载 MP4 或包含素材版本、提示词、任务记录的 ZIP。模拟图片为程序绘制、模拟旁白为静音，仅用于流程验证。

每张参考素材可单独报价重做，修改主图使派生角度及关联分镜失效；修改风格、角色、场景或道具时先预览影响，保留历史图片和无关素材。历史素材版本只读可查，不自动新增付费重试。已确认素材仍以文件内容哈希校验，文件被改动或丢失时拒绝继续。

字幕由本机中文字体栅格化叠加，不依赖 libass；可用 `LYPIT_FONT` 指定 TTF/OTF/TTC 字体。首版是分句时间估算，不是逐词强制对齐。

转场在分镜阶段规划：`cut` 直接剪切，`match` 按动作关系设计后剪切，`dissolve` 为0.3秒叠化。角色一致性依赖参考图、供应商模型和人工审核，不承诺生成结果完全无漂移。视觉模型检查参考资产、比较分镜候选，并检查生成视频的起始、中间与结束帧和前镜真实结束帧；最终动作与叙事连续性仍需人工看片验收。

## 模型服务

点击侧栏“模型服务”打开设置弹窗：左侧依次为模型接入、制作能力、高级配置。模型接入包含本地 CLI 和远程 API 两个入口，允许按制作步骤混用；切换入口不会自动改变已有绑定。

### 本地 CLI

支持 Codex、Claude Code、Gemini 的固定适配器。页面检测安装、版本和可用的本机登录状态，支持自定义绝对可执行路径、默认或手填模型 ID。Gemini 的登录状态显示未核实时，需在本机终端确认；不会自动安装或登录。连接检测只执行版本、登录状态或模型目录命令，不发起推理或生图。

Codex 配置页自动读取所选 CLI 的真实模型目录，展示模型名称、ID，以及目录支持的推理强度和 Fast 服务档位；“沿用 CLI 配置”不传入覆盖参数。草稿路径无需先保存即可读取，刷新目录不修改制作绑定或发起生成。目录按实际可执行文件、版本和配置环境在服务进程内缓存5分钟，重启后重新读取；读取失败时保留同一配置的上次成功目录并标记过期，没有缓存则仅提供默认与手填入口，不使用写死的模型名单。目录可见不代表模型权限或生图能力已经验证。Fast 可能增加额度消耗或费用。

CLI 可负责剧本、分镜的结构化 JSON 规划，以及生成图片。Codex 可选择“Codex 生图 · 自动调用 imagegen”：复用 CLI 已有的 `$imagegen` Skill 与账户，不需要填写工具说明或 Skill 路径；上方模型组织调用，实际图片模型由工具决定。页面提供待验证的图片尺寸和参考数量配置，只有确认单张测试报价并通过验证后才能绑定制作。新建 Codex 配置默认提供此方式，旧配置保留原通用方式，可手动切换。

Codex 生图把提示词经标准输入传递，参考图通过 `-i` 传入；从事件中的本次线程 ID 收取 `CODEX_HOME/generated_images/<thread-id>` 下的 `ig_*` 图片，或没有 `ig_*` 时的 `call_*` 图片。仅接受唯一、非旧任务、非符号链接的真实文件，复制到独立任务目录后检查格式、完整解码和准确尺寸。不会搜索其他线程、拿历史图补结果、静默缩放图片或删除 CLI 源产物。响应与任务产物保留供恢复，取消后停止子进程，恢复不再次执行 CLI。仅预览、无文件、尺寸不符或多张歧义输出均报告失败。

Claude Code、Gemini 和 Codex 的“已有工具或 Skill”方式继续使用通用适配器：在高级配置声明图片能力、精确尺寸、格式和参考图数量，并在接入页填写工具说明、可选 Skill 文件路径。工具必须生成真实 PNG/JPEG/WebP 文件并返回任务目录内的路径；只输出提示词、占位图或目录外文件会被拒绝。每次执行使用独立目录，不改写官方 Skill、CLI 安装文件或全局配置。

生图绑定前必须查看并确认一次单张图片验证报价，验证通过后才可选择。CLI 内部工具调用数量与费用不可可靠获知，报价显示未知，不将本地执行或订阅登录描述成免费；生成失败和结果未知时不自动重跑。现有工具可能需要额外权限或不支持无人值守，此时保留失败记录，不绕过权限。改动 CLI、模型或生图工具配置后需要重新验证；更改已绑定的生图服务前先将相关绑定切回可用服务再保存。

### 远程 API

- `mock`：本地模拟，不联网生成，可以与真实服务混用，界面明确提示。
- `openai`：使用 `/chat/completions`、`/images/generations`、`/images/edits`（multipart `image[]`）和 `/audio/speech`；保留结构化文本、生图编辑、视觉审核和配音能力。
- `anthropic`：使用原生 Messages API，以 `x-api-key` 鉴权，支持结构化文本规划与图片视觉审核。
- `gemini`：使用原生 `generateContent`，以 `x-goog-api-key` 请求头鉴权，支持 JSON 文本规划与图片视觉审核。API Key 不放入 URL。
- `seedance`：调用 `tools/seedance`，仅连接方舟官方 API；支持已审核的多图片参考，不支持首尾帧。首个视频报价时自动构建 CLI，也可设置绝对路径 `SEEDANCE_BIN`。

原生接口实现依据 [Anthropic Messages 文档](https://platform.claude.com/docs/en/api/http/messages) 和 [Gemini API 文档](https://ai.google.dev/api/generate-content)。兼容服务的参数仍需实际验证，不能只改地址假定所有能力通用。模型目录支持读取和手动填写；连接检测不代表生成权限或全部能力已经实测。

凭据来源可选“页面填写 · 本地加密保存”或“后端环境变量”。页面填写的 Key 只发送给本机后端，保存后清空输入，不回显原文，不写入浏览器持久化、SQLite、项目导出或报价快照。后端在私有数据目录 `secrets/` 下用 AES-GCM 加密，`master.key` 与不可变版本密文分文件保存，目录权限0700、文件0600。替换凭据先写新密文，再提交版本引用；失败时旧引用保持有效。清除当前绑定保留旧密文供历史任务恢复。请同时备份主密钥和密文，缺失主密钥不能解密；本地加密无法抵御整个用户目录被读取。

环境变量方式继续只填写变量名称，例如 `TEXT_API_KEY`、`IMAGE_API_KEY`、`VOICE_API_KEY`、`VISION_API_KEY`、`ARK_API_KEY`；配置进程环境后重启后端。两种来源不静默回退，文件解密失败时明确报错。供应商地址是你显式选择的凭据接收方，请核实地址。

分镜参考按实际镜头计算，最多六张（最多三个角色视图＋场景＋道具＋前镜）；双候选审核最多八张输入，视频三帧审核最多八张输入。角色其余视图必须引用已审核主图。配置的参考能力不足时阻止执行；声明兼容协议不代表真实图片编辑能力已经验证。模型不满足能力或未读取到凭据时阻止生成，不静默删减输入。

价格可记录单位、来源与核实日期。按次计费可估算本批范围；Token 等动态计费缺少可靠上界时显示未知，需要在确认页明确接受按实际用量计费。Seedance 使用 CLI 的独立报价和真实 completion_tokens 估算，非账户账单。普通兼容服务只展示其返回的用量，不从缺失字段编造实际费用。

连接检测只访问模型目录，Seedance 仅检查本地凭据；不代表生成权限或所有能力已经实测。

## 数量、版本与数据升级

报价按阶段独立计算：故事分析仅一次文本调用；角色主图每角色一张；其他视角每角色三张，场景和关键道具按清单实际缺少数量生成，图片审核另外列出。分镜阶段最多12镜×两张初始候选，另含每镜最多一张条件修复，共最多36张分镜图片，不包含角色、场景或道具生成。各阶段的额度不是金额封顶，未触发的条件任务不提交。局部重做单独报价，复用无关素材。

报价绑定项目版本、参考素材版本及文件哈希、模型配置和任务范围；修改或确认素材后旧报价失效。分镜与视频也绑定锁定的素材快照，不能跳过人工确认或通过接口扩大任务数量。

数据库格式版本为4。旧库启动时先完整备份为 `data/studio-before-v4-*.db` 再事务迁移。保留旧项目、分镜、素材、凭据引用及任务；旧项目可显式导入历史参考素材，人工确认后复用，缺失背面图另行报价。已确认历史任务仍按原有三视图授权恢复，不自动追加新任务；旧的未确认整套分镜报价不能用于新流程。较新格式拒绝写入。

回滚时停止后端，将明确选择的备份文件恢复为 `studio.db`，同时保管现有数据库及相关 WAL 文件；不要在运行中替换数据库。升级到新素材流程不会自动调用模型。

## 持久化与恢复

SQLite 保存项目、版本、任务、报价、供应商配置快照（仅凭据引用）和请求状态，本地文件保存媒体及已返回的模型响应。默认并发：图片2、视频2、渲染1。候选以独立生成意图与参考内容哈希标识：同一候选恢复复用，不同候选即使提示词相同也不会错误合并。

付费请求前保存提交意图。同步请求的响应若已保存，后续解析或下载失败可以恢复处理；网络中断且没有结果记录时暂停核对，不自动重发。Seedance 已知任务恢复只查询和下载，未保存ID的任务需要到控制台人工核对。CLI 强制终止可能留下空锁目录，请在确认对应旧进程已退出后，仅移除那个明确的空锁目录，再恢复。

取消只停止新增提交和本地等待；供应商已接收的任务仍可能执行并计费。失败后先使用“恢复已确认任务”，不要换项目重复提交。`data/` 含完整故事、提示词、素材和任务详情，请按私有文件保护并在后端停止后备份整个目录。数据目录带进程排他锁，同一目录不能启动多个后端实例。后端当前以 macOS/Linux 为运行目标。

## Hypit 与剪辑

FFmpeg 根据镜头计划执行剪切、叠化、旁白混合、可选音乐和字幕。Hypit 接管最终本地规范化和导出 Run，执行 `check`、`plan`、`build --follow`、`get`，保留可追踪 Result；不会为合成请求额外的云端生成。当前不是 Hypit Studio 的逐镜可视时间轴编辑器。

最后检查成片55～65秒、486×864（精确9:16，源素材按480p生成后居中裁切）、音轨存在、媒体可解码和超过0.5秒的黑帧；检查失败保留素材和报告，不自动付费修复。默认背景音乐未提供时不添加音乐。
